#  Personal Portfolio Website

##  Project Title
Personal Portfolio Website


##  Description
This is a responsive personal portfolio website built using HTML, CSS, Bootstrap, and JavaScript.  
It showcases my skills, projects, and contact information in a modern UI design.


##  Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript


##  Features Implemented
- Fully responsive design (mobile, tablet, desktop)
- Bootstrap-based layout system
- Hero section with auto greeting and typing effect
- Projects showcase section
- Skills display section
- Contact form UI
- Smooth scrolling and animations
- Hover effects on cards and buttons
- Clean and modern UI design
